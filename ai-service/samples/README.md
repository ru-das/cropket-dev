# Sample photos

Drop real onion photos here as `onion/*.jpg` (3 photos of one lot is enough
to try) and `pytest -q` will grade them automatically —
`tests/test_samples.py` skips itself when this folder is empty, so nothing
breaks without photos.

SPEC.md §5.5 step 7 asks for a 200+ photo labelled test set with measured
accuracy in this README — that is out of scope for the prototype
(CLAUDE.md §9.5). Add it if the team keeps building after the demo.
